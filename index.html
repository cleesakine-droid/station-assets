Features

为什么用 NexusAPI

省掉每个模型各开一个账号、各绑一张外币卡的麻烦，一个账户全搞定。

计价透明

每次调用按实际 Token 用量实时扣费，输入、输出、缓存读取分开计价。余额和每一笔用量明细在控制台随时可查，没有打包暗扣。

按量付费

按实际消耗的 Token 扣费，用多少付多少，没有月费绑架。轻度使用一个月可能就几块钱。

双格式标准接口

同时兼容 Anthropic 与 OpenAI 两套格式。工具填 /v1 或 Claude 原生地址都能通，换工具不用换站。

一个令牌走全站

控制台创建一个 sk- 令牌即可调用站内全部模型，随时可查用量、可停用，泄露了删掉重建就行。

FAQ

常见问题

充值未到账 / 充值遇到问题怎么办？
先别重复支付，避免重复扣款。保留好支付成功截图、账号名与支付时间、金额，通过站内公告的联系方式反馈，核对后会尽快处理。
令牌填进工具后调用报错？
先对三样：Base URL 是否为 https://api.hgapi.de5.net（OpenAI 格式工具填 /v1 版本地址）、令牌是否完整复制、所选模型名是否与定价页一致。三样都对还报错，再看控制台的使用日志，里面有每次请求的结果。
余额是怎么扣的？
每次请求结束按实际 Token 用量 × 模型单价实时扣除，输入、输出、缓存读取分开计价。控制台的使用日志里每一笔都可查，不存在打包暗扣。
