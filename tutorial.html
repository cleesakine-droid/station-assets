接入教程

所有工具的接法都是同一件事：把接口地址换成 NexusAPI 的，再填上你的令牌。区别只在你用的工具把这两样东西放在哪里，按下面的工具找对应那一节即可。

开始前，先备齐三样

  1. 账号：在站内注册并登录，进控制台。
  2. 令牌：控制台「令牌」页新建一个，形如 sk-xxxxxxxx，创建后完整复制保存（只完整显示一次）。
  3. 接口地址（二选一，按工具的格式选）：Anthropic 格式 https://api.starwheel.net；OpenAI 格式 https://api.starwheel.net/v1。

1Claude Code

走 Anthropic 格式。改环境变量两行，或者写进配置文件，二选一。

终端（macOS / Linux）— 临时生效，关窗口失效
export ANTHROPIC_BASE_URL="https://api.starwheel.net"
export ANTHROPIC_AUTH_TOKEN="sk-你的令牌"
claude
配置文件 ~/.claude/settings.json — 长期生效（推荐）
{
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.starwheel.net",
    "ANTHROPIC_AUTH_TOKEN": "sk-你的令牌"
  }
}
最常见的坑：电脑上如果还留着 ANTHROPIC_API_KEY 环境变量，它会抢占计费路径。接本站只用 ANTHROPIC_AUTH_TOKEN，把 ANTHROPIC_API_KEY 清空或删掉。
  • Windows：同样的两个变量名，在 PowerShell 里用 $env:ANTHROPIC_BASE_URL="https://api.starwheel.net" 这样写，或直接改 settings.json，一样有效。
  • 多个站来回切换：用 CC Switch 管理配置，一键切换，不用来回改文件。

2Codex 与其他 OpenAI 格式工具

走 OpenAI 格式，地址带 /v1 结尾，这是和 Claude Code 唯一的区别。

通用填法
Base URL : https://api.starwheel.net/v1
API Key  : sk-你的令牌
Model    : 在站内定价页查模型名，照抄

3Cline / Continue（VS Code 插件）

在插件设置里选 API 提供方为 OpenAI Compatible（或 Anthropic），然后填三样：

  • Base URL：OpenAI 格式填 https://api.starwheel.net/v1；选 Anthropic 提供方则填不带 /v1 的地址。
  • API Key：你的 sk- 令牌。
  • Model：定价页上的模型名，一字不差。

4Cherry Studio / ChatBox 等聊天客户端

设置 → 模型服务 → 添加自定义提供商，同样三个格子：

填法
API 地址 : https://api.starwheel.net/v1   （客户端若自动补 /v1 则只填域名部分，按客户端提示来）
API Key  : sk-你的令牌
模型     : 手动添加定价页上的模型名
  • 填完先点客户端里的「检查 / 测试连接」，通过了再开聊，能少走很多弯路。

5curl / Python SDK 自行调用

curl（OpenAI 格式）
curl https://api.starwheel.net/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"model":"定价页的模型名","messages":[{"role":"user","content":"你好"}]}'
Python（openai 库，只改 base_url）
from openai import OpenAI
client = OpenAI(base_url="https://api.starwheel.net/v1", api_key="sk-你的令牌")

6报错先对这四样

  • 401：令牌不对或没复制全 — 回控制台令牌页核对，必要时删掉重建。
  • 404 / 模型不存在：模型名和定价页对不上 — 照抄，别自己改大小写和版本号。
  • 地址报错：格式选错 — Anthropic 工具不带 /v1，OpenAI 工具带 /v1，这是最常见的填错。
  • 余额不足：控制台钱包看余额与使用日志，每笔扣费都有记录。
